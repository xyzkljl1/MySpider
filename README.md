# MySpider

MySpider 由独立的入口程序、统一调度核心和来源模块组成。入口程序定期从多个来源更新作品信息，对候选作品按 RJ 编号统一去重，并将下载任务交给对应来源模块执行。ASMR.ONE 是主要来源；当多个来源同时提供同一作品时优先使用 ASMR.ONE。Telegram 来源每七天按游标增量检查指定频道中发布已超过一天的中文音声和汉化音声作品，并从对应讨论中取得发布文件作为补充来源。扫描时会先确认可下载文件；没有讨论或目标文件的作品会在当轮跳过，游标不会越过尚未解决的作品，临时请求失败也不会被当作来源不可用。

程序会复用未完成的临时下载，检查作品文件是否全部到达，并完成必要的音频转换和分类。ASMR.ONE 只下载文件扩展名和文件签名都能确认为音频或视频的媒体文件，跳过图片、文本等非媒体附件。ASMR.ONE 使用持久游标跳过已经确认无需下载、已经完成或来源确实不可用的旧作品；临时请求失败不会推进游标。入口程序统一管理作品的临时目录、同盘中转目录和最终分类目录，来源模块将完成后的文件清单交给入口整体落盘；统一调度器只负责排除无需下载的 RJ、限制并发作品数量以及跟踪当前下载队列。

入口程序从 `config.json` 读取下载目录、FFmpeg 路径、共用代理和 Telegram 长期凭据。首次登录需要验证码时，程序会在控制台中要求人工输入；不支持需要两步验证密码的账户。登录会话和频道扫描游标保存在程序运行目录下的 `.TelegramData`，ASMR.ONE 游标保存在 `.asmrone`；部署时应保留这两个持久状态目录，后续启动通常不需要再次验证或重新扫描已经处理的旧作品。
