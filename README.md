# MySpider

MySpider 由独立的入口程序、统一调度核心和来源模块组成。入口程序定期从多个来源更新作品信息，对候选作品按 RJ 编号统一去重，并将下载任务交给对应来源模块执行。ASMR.ONE 是当前启用的主要来源；当多个来源同时提供同一作品时优先使用 ASMR.ONE。Telegram 来源可以通过配置登录并确认指定频道，目前尚未启用作品列表获取和文件下载。

程序会复用未完成的临时下载，检查作品文件是否全部到达，并完成必要的音频转换和分类。入口程序统一管理作品的临时目录、同盘中转目录和最终分类目录，来源模块将完成后的文件清单交给入口整体落盘；统一调度器只负责排除无需下载的 RJ、限制并发作品数量以及跟踪当前下载队列。

入口程序从 `config.json` 读取下载目录、FFmpeg 路径、共用代理和 Telegram 长期凭据。首次登录需要验证码或账户已启用的两步验证密码时，程序会在控制台中要求人工输入；登录会话保存在程序运行目录中，后续启动通常不需要再次验证。
